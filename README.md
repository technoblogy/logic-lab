# Logic Lab
Provides a selection of 12 logic gates that you can interconnect with patch cables to make a variety of different logic circuits. This version is implemented using an AVR microcontroller:

For more information see <http://www.technoblogy.com/show?4FFY>.

Alternatively see [Logic Lab 1G](https://github.com/technoblogy/logic-lab-1g) which is implemented using 12 individual logic gates.
